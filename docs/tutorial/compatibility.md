# 兼容性表格导读

uni-app x 在不同平台（Android、iOS、鸿蒙、微信小程序、web）、在不同os版本、在不同模式（vdom或蒸汽）、在不同运行环境（uvue页面或uts原生插件环境），存在某些功能的差异。
由此产生兼容性表格。

为便于阅读，表格会合并兼容性一致的列，隐藏无需单独说明的版本列。列被合并或隐藏，不代表对应环境不支持。

## 表格内容

| 内容 | 含义 |
| --- | --- |
| `√` | 支持，未单独限定起始版本 |
| `x` | 不支持 |
| 版本号，如 `4.25` | 从该 HBuilder 版本开始支持 |
| 系统版本号，如 `15.0` | 从该操作系统版本开始支持，需结合所在表头判断 |
| 空白、`-` | 未标注，不能据此确定支持或不支持 |

因老版红色图标的 HBuilder 已于 2019 年下线，本文档网站中的 HBuilder 泛指 HBuilderX 和 HBuilderV。两者的版本号一致，IDE 与 uni 引擎的版本号保持一致。

版本号末尾的 `+` 在表格中会被省略。例如 `4.25+` 显示为 `4.25`，仍表示从该版本开始支持。

## 表头与展示方式

### 平台与二级表头

一级表头按平台组织。具体显示哪些平台，取决于当前功能的兼容性配置。

### 平台
- Web
- 微信小程序
- 支付宝小程序
- Android
- iOS
- HarmonyOS

同一平台需要区分多个环境时，会显示二级表头：

| 二级表头 | 含义 |
| --- | --- |
| VDOM | 页面中的虚拟 DOM 渲染模式 |
| Vapor | 页面中的蒸汽渲染模式 |
| VDOM UTS 插件 | VDOM 模式对应的 UTS 插件原生运行环境 |
| Vapor UTS 插件 | Vapor 模式对应的 UTS 插件原生运行环境 |
| UTS 插件 | VDOM 与 Vapor 插件兼容性满足合并条件后的共同列 |
| 系统版本 | 该平台需要单独说明的操作系统版本要求 |
| uni-app x | 页面兼容性已合并，但同一平台还有系统版本或 UTS 插件等其他列需要展示 |

例如，Android 需要区分页面模式与插件环境时，表格会按如下方式展示：

同一平台最终只剩一列时，仅显示平台或对应环境的名称，不额外增加一层表头。

### 小程序文档链接

微信、支付宝小程序的文档链接放在对应平台的表头上；采用两级表头时，链接位于一级平台名称上。

有明确对应文档时，点击跳转到该文档；未配置具体地址时，按 API 或组件名称搜索。微信搜索地址形式为：

```text
https://developers.weixin.qq.com/doc/search?q=getCurrentPage&sector=miniprogram
```

没有具体功能名称的汇总表格使用对应平台的文档首页。

## 版本列合并规则

### VDOM 与 Vapor

以下情况不需要拆开显示 VDOM 与 Vapor，会合并为一个平台列，保留 VDOM 列中的值：

- 两者兼容性相同，包括相同版本号、同为 `√` 或同为 `x`。
- Vapor 未单独标注。
- App 平台的 VDOM 已标注支持，Vapor 标注的是该平台的默认起始版本。

App 平台使用的默认 Vapor 版本如下：

| 平台 | 默认 Vapor 版本 |
| --- | --- |
| Android | `5.21` |
| iOS | `5.11` |
| HarmonyOS | `5.0`、`5.01` |

例如，Android 的 VDOM 标注为 `4.25`，Vapor 标注为 `5.21`，表示该功能在 Android Vapor 推出时就已支持，表格合并为 Android，显示 `4.25`。这个值不表示 Android Vapor 在 `4.25` 就已存在。

若 VDOM 为 `x`、Vapor 为 `5.21`，则必须分别展示，避免将 Vapor 的支持误读为两种模式都支持。

Web 和小程序目前只按兼容性相同或 Vapor 未标注来合并，不套用 App 的默认 Vapor 版本规则。例如 Web 的 VDOM 为 `4.0`、Vapor 为 `5.32` 时，仍分别展示。

多行表格需要每一行都满足合并条件，才会合并整列；任意一行存在需要说明的差异，就保留 VDOM、Vapor 两列。

### UTS 插件

页面环境与 UTS 插件 `utssdk` 的原生运行环境可能存在差异，因此 App 平台有时需要单独列出 UTS 插件版本。

UTS 插件列按以下规则简化：

- 某模式的插件版本与对应页面版本在每一行都一致时，隐藏重复的插件列。
- 保留下来的 VDOM、Vapor 插件列，若每一行都兼容性相同，或 VDOM 插件已支持且 Vapor 插件为该平台的默认起始版本，则合并为 `UTS 插件`，去掉名称中的 `VDOM`。
- 仅配置 VDOM 插件、未配置 Vapor 插件时，不据此认定两者兼容性一致。该列若未因与页面版本重复而隐藏，仍保留 `VDOM UTS 插件` 名称。
- 整列未标注的插件版本不展示。

页面中的 VDOM/Vapor 与插件中的 VDOM/Vapor 分别判断，不因页面列合并就自动合并插件列。

### 操作系统版本

系统版本列只在需要单独说明时显示。例如，某 API 的 iOS 页面版本为 `4.25`，iOS 系统版本为 `15.0`，表示需要同时满足 HBuilder `4.25` 及以上、iOS `15.0` 及以上。

默认系统版本如下：

| 平台 | 默认系统版本 |
| --- | --- |
| Android | `6.0` |
| iOS | `14.0` |
| HarmonyOS | `6.0` |

整列为空、仅标注支持，或所有值均不高于默认系统版本且无需额外说明时，不展示该系统版本列。低于默认系统版本的值不单独展示；如果一列中还有更高的系统要求，则保留该列。

## 空列与总体支持状态

整列未标注的内容会被隐藏，避免表格出现没有信息的空列。这适用于页面版本、Vapor、UTS 插件和系统版本列。

悬浮表格的总体状态在用于展示的列被合并、删除之前计算：

| 图标状态 | 含义 |
| --- | --- |
| 绿色对勾 | 所有参与判断的平台和环境均已标注支持 |
| 红色叉号 | 所有参与判断的平台和环境均为 `x` |
| 部分支持图标 | 存在支持、不支持或未标注的混合情况，或信息不足以判断全部支持 |

状态计算有以下约定：

- 系统版本、Vapor、UTS 插件允许不单独配置，整列为空时不参与状态判断；一旦该列有配置，仍需要结合各行内容判断。
- Web、App 等基础平台的页面版本缺失时，即使该列最终被隐藏，也不能据此判为全部支持。空白、`-` 与 `x` 混合时也不能判为全部不支持。
- CSS 表格中的小程序兼容性按需填写：整列未填写时，不影响总体支持状态；填写后参与判断。
- 未配置任何有效兼容性信息时，可能显示占位符或不生成表格，不代表支持。

因此，不能只根据最终可见的版本列推断总体状态。需要确定某个平台是否支持时，应以该平台的明确标注为准。
