## border-bottom-right-radius



设置元素边框右下角的圆角半径。允许指定一个或两个半径值来定义椭圆形的角。如果只指定一个值将创建一个均匀的圆角。如果指定两个不同的值，第一个值将用于半长轴，第二个值将用于半短轴，从而可以创建椭圆形的圆角，使其在水平和垂直方向上具有不同的曲率。

### 语法
```
border-bottom-right-radius: <length-percentage>{1,2};
```



### 值限制
- length
- percentage




### 默认值 @default-value 
 `0`







### tips
- App平台蒸汽模式不支持 rpx 单位。
