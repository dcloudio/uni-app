## border-top-left-radius



border-top-left-radius 用来设置元素左上角的圆角效果。这段圆弧（角）可以是圆或椭圆的一部分。如果其中有一个值为 0，那么将无圆角效果（见 border-top-left-radius 取值方式)。

### 语法
```
border-top-left-radius: <length-percentage>{1,2};
```



### 值限制
- length
- percentage




### 默认值 @default-value 
 `0`







### tips
- App平台蒸汽模式不支持 rpx 单位。
