# uni-badge-view 数字角标

## 用途和场景

数字角标（徽章）组件，用于在元素周围展示消息提醒，包括红点、数字或文字角标。常见于按钮、列表项、九宫格图标等需要提示“有新内容”的位置。

## 使用方式（职责分工）

badge组件有多种用法：

1. 独立显示
	如果没有slot内容，视为要显示独立的红点和数字，此时不是角标，就是普通的红点和圆背景数字。
	在按钮或列表项的右侧，独立显示数字。也可以显示红点，但这种场景数字更多一些。

2. 作为一个容器组件，包含一个slot，在包裹内容的右上角显示一个角标view。
	badge组件包裹一个目标view时，badge组件内部的角标view的中心点位于目标view的右上角顶点。
	此时角标view是通过transform位移到右上角的，实际内容已经超出了容器本身。
	所以需要注意容器的父级的设置，留出超出容器的尺寸（即top和right边距需要留出角标view的高度和宽度的一半），避免被父级裁剪。

- 组件内部负责：
  - 无 slot 内容时，独立显示红点或数字/文字，此时不是角标，而是普通的红点或圆底数字。
  - 有 slot 内容时，作为容器包裹目标内容，并把角标定位到目标内容的右上角（角标中心位于目标内容右上角顶点）。
- 使用者负责：
  - 角标是通过 `transform` 位移到右上角的，实际绘制已超出容器本身。包裹内容时，务必给角标的父级预留出超出容器的空间（top、right 各留出角标尺寸的一半），避免角标被父级裁剪。
  - 通过 `badge-class` 外部样式类定制角标外观（前景、背景、位置等）。角标本质是一个 `text` 组件，可覆盖其各类样式。

## text 属性的语义

`text` 的不同取值代表不同效果：

- 值为 `"0"`：不显示角标，此时默认直接显示 slot 子内容、不包裹外层，减少层级、提升性能。
- 值为 `""`（空字符串）：显示一个长宽为 8px 的红色圆点。
- 其他文字：显示为圆角红底圈套文字的角标。

## 基本用法

```vue
<template>
  <!-- 独立红点 -->
  <uni-badge-view />

  <!-- 独立数字 -->
  <uni-badge-view text="9" />

  <!-- 作为容器，在内容右上角显示角标 -->
  <uni-badge-view text="99+">
    <view class="avatar"></view>
  </uni-badge-view>
</template>
```

## 自定义样式

通过 `badge-class` 外部样式类定制角标：

```vue
<uni-badge-view text="HOT" badge-class="my-badge">
  <view class="content"></view>
</uni-badge-view>
```

```css
.my-badge {
  background-color: #6f42c1;
  color: #ffff00;
}
```

## 注意事项

- 组件包裹内容时，角标绘制会超出容器，务必给父级预留空间，避免被 `overflow: hidden` 裁剪。
- `text` 为 `"0"` 时默认不包裹内容；若存在多个子 slot 且需要保留包裹层以稳定 flex 方向，可将 `always-wrap-with-content` 设为 `true`。
