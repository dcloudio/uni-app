## 1.4.0（2026-11-14）

- 范围选择宽屏左右横排时，在两个日历之间增加一条细分隔线
- 修复范围模式已有初始值时第二个日历固定显示开始月下一个月的问题：第二个日历优先展示结束日期所在月
- 修复 Web 端弹层滚动到边缘后带动背后页面滚动的滚动穿透问题
- 调整弹层形态：手机端（含宽屏与 Pad）统一从底部弹出；仅 Web 宽屏锚定触发区下方，宽屏范围选择仍左右横排

## 1.3.0（2026-11-14）

- 宽屏（宽度不小于 768px）弹层改为锚定触发区下方展示，空间不足时自动改到上方；该布局在 App、小程序、Web 全平台生效
- 修复微信小程序“More than one slot named”告警与第二个日历首尾标签插槽不渲染的问题：首尾插槽按当前展示月份排他地路由到对应日历
- 修复 Android 上关闭按钮、确定按钮点击无响应的问题
- 修复窄屏紧凑模式下范围选中样式断裂：紧凑样式内置到日历视图，药丸与条带同高、单侧圆角恢复
- 示例页：快捷选择支持横向滚动；重排为单选、范围、单选+确认、范围+确认各「基本用法 + 自定义样式」共 8 例

## 1.2.0（2026-11-14）

- 新增 `confirm` 属性：开启后弹层底部显示已选日期预览，左上角变为取消、右上角为确定，点击确定才提交并关闭弹层；确定、取消文字内置五种语言
- 新增 `preview-result-class`、`preview-result-text-class` 外部样式类
- 修复切换月份后 `Esc` 无法关闭弹层的问题（弹层打开时全局监听 Esc）
- 手机端范围模式在窄屏空间足够时同时完整展示两个日历，并自动缩小日期单元格高度
- 移除 `close-on-select`、`readonly` 属性，单日选择与范围选择完成后默认自动关闭

## 1.1.0（2026-11-14）

- 新增 `uni-calendar-picker` 日历选择器，支持单日选择与日期范围选择
- 手机端为接近全屏的底部弹层，宽屏为居中弹层；支持返回键、下拉与 Esc 关闭
- 范围模式内置两个独立翻月的日历，共享同一份首尾日期
- 新增 `update:modelValue`、`update:rangeStart`、`update:rangeEnd`、`change`、`popupopened`、`popupclosed` 事件
- 新增 `default`、`title`、`range-start`、`range-end` 插槽
- 新增 `open`、`close`、`clearRange` 方法
